# Banking Customer & Transaction Analytics Dataset

Synthetic portfolio dataset created for an end-to-end Data Analyst project.

## Tables
- customers.csv — 5,000 customers
- accounts.csv — 7,500 accounts
- products.csv — 8 banking products
- transactions.csv — 120,000 transactions
- customer_products.csv — customer-product relationships
- data_dictionary.csv — field definitions

## Period
Transaction data covers January 1, 2025 through December 31, 2025.

## Currency
INR (Indian Rupees).

## Important
This is a synthetic dataset created for portfolio/learning purposes. It contains no real customer or bank data.
